# Weekly Planner

A minimalist weekly planner web application inspired by [Tweek](https://tweek.so/), optimized for both desktop and mobile devices.

## Features

- **Weekly Calendar View**: Clean, grid-based layout showing 7 days of the week
- **Task Management**: Add, edit, and delete tasks with ease
- **Drag & Drop**: Move tasks between days effortlessly
- **Color Coding**: Customize tasks with 8 different colors
- **Someday Section**: Store tasks without a specific date
- **Responsive Design**: Optimized for desktop, tablet, and mobile screens
- **Local Storage**: All tasks are saved automatically in your browser
- **Week Navigation**: Navigate between weeks with simple arrows
- **Mark Complete**: Toggle tasks as completed with a checkmark

## How to Use

### Adding Tasks

1. Click the "+ Add task" area under any day
2. Type your task and press Enter or click outside to save
3. Press Escape to cancel

### Editing Tasks

- Click on any task to edit its text
- Press Enter to save or Escape to cancel

### Task Actions

When you hover over a task, you'll see action buttons:
- **✓** - Mark as complete/incomplete
- **🎨** - Change task color
- **✕** - Delete task

### Drag and Drop

- Click and hold a task to drag it
- Drop it on any day or the "Someday" section
- Works across all days and the someday section

### Color Coding

1. Hover over a task and click the 🎨 color button
2. Choose from 8 available colors
3. Click outside to close the color picker

### Week Navigation

- Use the arrow buttons in the top right to navigate between weeks
- The current month and year are displayed in the header

## Responsive Design

The planner automatically adapts to different screen sizes:

- **Desktop**: 7-column grid showing the full week
- **Tablet**: 4-column grid with wrapped days
- **Mobile**: 2-column or 1-column layout for easy scrolling

## Browser Compatibility

Works on all modern browsers:
- Chrome/Edge (recommended)
- Firefox
- Safari
- Opera

## Data Persistence

Tasks are automatically saved to your browser's local storage. Your data persists between sessions as long as you:
- Use the same browser
- Don't clear browser data
- Stay on the same domain

## Getting Started

Simply open `index.html` in your web browser. No installation or setup required!
